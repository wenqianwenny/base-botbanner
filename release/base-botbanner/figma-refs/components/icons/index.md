## Banner Usage Guide

For bot banners, prefer **outlined** icons for:
- Workflow node icons
- Toolbar action icons
- Inline feature indicators

Use **filled** icons for:
- Tab bar active states
- Status indicators that need emphasis
- AI feature markers
